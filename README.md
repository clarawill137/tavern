# 🕯️ Таверна — приватный ролевой форум для своих + ИИ

Мультиплеерная ролевая: живые игроки пишут за своих персонажей, ИИ через OpenRouter играет ГМа и НПС, летописец ведёт хронику, траты считаются по каждому — в конце месяца легко скинуться.

Без зависимостей: чистый Node 22+ (встроенный SQLite), один контейнер.

## Что умеет

- **Инвайты** — регистрация только по коду, первый аккаунт = админ
- **Комнаты** двух типов: 📜 форум (длинные посты, книжная вёрстка, `*курсив*` для действий) и 💬 чат (служебки, флуд), разделы-категории
- **Персонажи-маски** — у каждого игрока сколько угодно, с эмодзи/цветом/био; пост «вне игры» от себя
- **ИИ-персонажи** — имя + модель OpenRouter + системный промпт; кнопка «✨ позвать ИИ» с необязательным указанием («пусть вбежит гонец»); ИИ видит описание локации, хронику, общий промпт мира и последние N постов
- **Летописец** 📖 — кнопка «обновить хронику»: дешёвая модель сводит события комнаты в хронологию, она хранится в комнате и подаётся ИИ в контекст
- **Лимиты и честный делёж** 💰 — дневной лимит $ на игрока (админ без лимита), страница трат за месяц: кто сколько сжёг, итого и поровну
- **Живые обновления** — SSE, посты прилетают без перезагрузки; «ИИ пишет…»
- Редактирование/удаление своих постов (админ — любых), подгрузка истории
- **Миры** со своими комнатами, промптом, лорбуками (импорт World Info из SillyTavern), картой с метками и временем истории
- **Боты в комнатах** и авто-ответ: бот сам отвечает на каждый пост в роли

### Life (v4) — движок жизни, как в расширении Life для ST

- **Летописец после каждого поста** (в историях; в чатах — по выбору): отмечает время, сытость/силы/чистоту/самочувствие, раны, состояние, одежду, вещи и подарки, вкусы, шкалы отношений, мысли, желания и задумки ИИ. Под постом — плашка с чипами, последнюю запись мира можно откатить
- **Карточка персонажа** — Личность · Жизнь · Гардероб · Вещи · Связи. Для ИИ ещё: «на уме», «хочет сам», что заводит, ухаживания, инициатива с задумками (⚡ — сделать в следующем ответе)
- **Связи** — 6 шкал в обе стороны (доверие, близость, влечение, ревность, напряжение, вина) и моменты пары
- **Приватность** — игрок сам решает, видят ли другие его «Жизнь» и «Связи»
- **Сцена** — настроение, близость Авто/Вкл/Выкл, 14 оттенков, беременность, «забота после»
- **Картинки через OpenRouter** (Nano Banana): портреты, образы в полный рост, вещи, кадры мест, карта мира по местам — метки встают сами
- Всё это подаётся ИИ словами, без цифр — в скрытых «Заметках к сцене»
- Палитры Графит / Бумага / Луна, аватарки в постах: баннер / портрет / мелкие

## Установка (свежий VPS, Ubuntu/Debian)

```bash
# 1. docker, если нет
curl -fsSL https://get.docker.com | sh

# 2. забрать код (как зальёшь в репу — замени URL) и собрать
git clone https://github.com/USER/tavern.git && cd tavern
docker build -t tavern .

# 3. запустить (данные живут в /opt/tavern-data, переживают пересборку)
docker run -d --name tavern --restart unless-stopped \
  -p 127.0.0.1:8081:8080 -v /opt/tavern-data:/data tavern
```

### Caddy (https + домен)

```
tavern.example.duckdns.org {
    reverse_proxy localhost:8081
}
```

`systemctl reload caddy` — и всё, сертификат Caddy возьмёт сам.

### Первый запуск

1. Открой сайт → **Регистрация** (первый аккаунт = админ, инвайт не нужен)
2. ⚙️ Админка → вставь **OpenRouter-ключ**, задай **промпт мира** и дневной лимит
3. Создай комнаты (разделы: Локации / Флуд / Служебное) и ИИ-персонажей
4. Нажми **＋ Инвайт** и раздай коды друзьям

## Обновление

```bash
cd tavern && git pull
docker build -t tavern . && docker rm -f tavern
docker run -d --name tavern --restart unless-stopped \
  -p 127.0.0.1:8081:8080 -v /opt/tavern-data:/data tavern
```

База (`/opt/tavern-data/tavern.db`) не трогается.

## Бэкап

```bash
cp /opt/tavern-data/tavern.db ~/tavern-backup-$(date +%F).db
```

## Заметки

- Ключ OpenRouter хранится в базе на сервере и наружу не отдаётся (API сообщает только «задан/не задан»).
- Лимит считается по реальной стоимости из ответов OpenRouter (`usage.cost`), сбрасывается в полночь по времени сервера.
- Модель летописца по умолчанию — дешёвый haiku; меняется в настройках.
- Админка → «Модели и ключ»: `Летописец Life` (пусто = как модель хроники), `Модель картинок` (по умолчанию `google/gemini-2.5-flash-image`), `Стиль картинок` (общий; у мира может быть свой).
- Летописец и картинки списываются с того, кто запостил или нажал «Нарисовать».
- Можно запустить и без докера: `DATA_DIR=./data PORT=8080 node server.js` (нужен Node ≥ 22.5).
